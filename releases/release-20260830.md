# release-20260830

Release type: Skirmish alpha

Release date: 30 August 2026

Release post: [Skirmish Alpha Release]({% link news/_posts/2026-08-30-skirmish-alpha-release.md %})


GitHub release: [release-20260830](https://github.com/OpenE2140/OpenE2140/releases/release-20260830)

## What's new
- Added basic Skirmish AI
- Added new maps
- Fixed rare crash, when Heavy Lifter was destroyed
- New design of DETECTOR (UCS vehicle)
- New unit: ORCA (UCS advanced submarine)
- Other small fixes and improvements

---

- enabled production slot hotkeys
- Mine no longer produces ore crates too quickly
- Debug Menu is now disabled by default
- Defense Tower now requires only Bio-Center to build (like in E2140)
- light vehicles can no longer crush infantry

For full changelog, see the [release page](https://github.com/OpenE2140/OpenE2140/releases/release-20260830) on GitHub.
